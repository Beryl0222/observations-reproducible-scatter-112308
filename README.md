# 重定位观测的可复现 Scatter 与伴随交付

稀疏卫星足迹事件及重复贡献资料。 仓库记录均为本地合成资料，不依赖外部数据服务。

## 数据约定

obs 是物理观测稳定身份，rev 为整数修订。同修订 origin 只是引用来源且业务值应一致，遇到同修订冲突的数据暂不能交付。高修订撤销代替旧事件，修订可以乱序送达且分批提交。

没有屏蔽目标时，foot 总和为一。存在屏蔽目标时，renormalize 保留有效目标并按原足迹份额重归一，无有效目标按拒绝解释。reject 只在没有被屏蔽的正足迹时使用。实际权重为 weight 乘采用后的足迹份额。

目标格分子为实值观测乘实际权的共有总和，分母为实权总和，分母为零时无观测。位型约定为 IEEE-754 binary64，每项乘积按 binary64，求和误差最多一 ulp，在输入相等情形须逐位复现，种子用于分子除分母后的汇总。

## 读取与核对

在 Python 3.11 环境执行 `python -m pip install -r requirements.txt` 安装数值依赖。
`python -m unittest discover -s tests -v` 读取 `data/exchange.json` 并核对资料结构与关键输入关系。
